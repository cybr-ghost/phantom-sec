# Security Policy

## Supported versions
Security reports are currently accepted for the latest code on the default branch.

## Reporting a vulnerability
Please do not publish exploit details or sensitive information in a public issue. Contact the repository owner privately through GitHub's available security reporting options.

## Project safety boundaries
Phantom Sec is for defensive, educational, administrative, and explicitly authorized work. The project does not accept credential theft, malware, stealth, destructive actions, doxxing, private-person tracking, or unauthorized access features.

## Module safety
Third-party modules are not executed by the current application. Manifest validation is not a sandbox or a security guarantee.
