# Project Overview

## What is Phantom Sec?

Phantom Sec is an open-source project that aims to bring defensive security, responsible OSINT, network diagnostics, and system administration tools into one organized application.

It is being built in small steps. The current version is an early Python command-line preview, not a finished security suite.

## Who is it for?

- People learning about computers and defensive security.
- Developers who want to contribute to an open-source project.
- System administrators who need simple local information tools.
- Users who want to understand basic network and file information.

You do not need to be a cybersecurity expert to get started.

## Main parts of the planned application

- **Tool list:** A place to find tools and understand what each one does.
- **Module Workshop:** A planned workspace for preparing and checking tool descriptions.
- **System dashboard:** A planned overview of your computer and Phantom Sec.
- **OSINT tools:** Planned helpers for researching appropriate public information.
- **Network tools:** Diagnostics for your own devices and networks you are allowed to check.
- **Reports:** Ways to save and review results.

## Safety rules

Phantom Sec is for learning, defensive work, and authorized testing.

- Do not use it to access systems without permission.
- Do not collect passwords or private credentials.
- Do not use it to track or expose private individuals.
- Do not automatically run untrusted community code.
- Explain what a tool does and what information it reads.

## Current platform

Linux is the first development target. Windows support is planned for later testing. macOS support may be considered in the future.

## Project status

The current preview includes a command-line app, 12 built-in tools, local history, and basic exports. Many larger features described in project documents are still planned.
