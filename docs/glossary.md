# Beginner's Glossary

A quick explanation of words you may see while using Phantom Sec.

| Word | Simple meaning |
|---|---|
| **CLI** | Short for command-line interface. It means using an app by typing commands in a terminal. |
| **Command** | Text you type to tell a program what to do. |
| **DNS** | The system that helps find the IP address connected to a domain name, such as `example.com`. |
| **Domain** | A website name, such as `example.com`. |
| **Hash** | A fixed-length result calculated from data. A SHA-256 hash can help compare files. |
| **IP address** | A network address used to identify a device or service. |
| **JSON** | A common text format for storing structured information. |
| **Module** | One individual tool inside Phantom Sec. |
| **OSINT** | Research using information that is publicly available. It must still respect privacy and the law. |
| **Python environment** | A separate place for a project to keep its Python packages. |
| **SQLite** | A small database stored in a local file. Phantom Sec uses it for history and settings. |
| **Terminal** | An app where you type commands. |
| **Virtual environment** | Another name for an isolated Python environment. |
