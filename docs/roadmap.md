# Development Roadmap

A checked box means the feature is present in the repository. It does not mean every platform has been fully tested.

## The foundation

- [x] Python package and command-line app.
- [x] Tool list and interactive terminal menu.
- [x] Built-in tool catalogue.
- [x] Local SQLite history, favourites, and settings.
- [x] JSON and CSV exports.
- [x] Beginner guides and glossary.

## Module Workshop

- [x] Create a JSON module description template.
- [x] Check a JSON module description.
- [x] Keep third-party code execution disabled.
- [ ] Define a reviewed module package format.
- [ ] Design clear permission prompts for future tools.

## Built-in tools

- [x] Basic computer and Python information.
- [x] Linux and Windows uptime information.
- [x] Combined read-only local system overview.
- [x] Memory, battery, process count, disk usage, and hostname checks.
- [x] File hash, metadata, directory size, and permission checks.
- [x] Local network interface information.
- [x] Forward and reverse DNS lookups.
- [x] Local subnet calculator.
- [x] URL structure, TLS certificate, and website security-header checks.
- [x] DNS records, public domain registration, and certificate transparency lookups.
- [ ] More local file inspection tools.
- [ ] More network diagnostics with clear permission and scope limits.
- [ ] More responsible public-source research helpers.

## User experience and quality

- [x] Automated tests and GitHub Actions workflow.
- [x] Installation and beginner usage guides.
- [x] Desktop interface with search, categories, favourites, and run history.
- [ ] Test supported platforms more thoroughly.
- [ ] Build and publish installable application packages.
- [ ] Publish a documentation website and community space.

## Next milestones

1. Keep the current code and automated checks reliable.
2. Improve the beginner experience and reporting.
3. Add useful local file, system, and network tools.
4. Expand responsible public-source research helpers.
5. Prepare easier installation packages.

Unchecked features are planned, not currently available.
